Описание сервиса `ImportCadFolderService`:

`ImportCadFolderService` читает документы через `ICadFolderDocumentReader`.
Маппер создаёт один объект с атрибутами; состав связывает сервис после поиска
существующих объектов. Все изменения принятых документов сохраняются одной
транзакцией через `IUnitOfWork`.

Ошибки чтения и атрибутов отклоняют отдельные файлы. Все документы с одинаковым
обозначением отклоняются; для совпадающих имён стандартных изделий применяется
та же политика. Неположительное количество или повтор одного компонента
отклоняет сборку. Один обход зависимостей выявляет отсутствующие компоненты,
циклы и распространяет отказ на родителей. Он выполняется повторно после
проверок существующих объектов, чтобы учесть новые причины отказа.

Идентификатор документа — имя файла на диске. Отсутствующий в папке компонент
не заменяется объектом из БД. Новые сборки используют найденные сущности детей,
поэтому повторный импорт не создаёт копии объектов.

Неизменённая версия пропускается, рабочая обновляется, для утверждённой создаётся
новая рабочая. Если все версии аннулированы, также создаётся новая рабочая версия.
Изменения проверяются до мутации сущностей. Отсутствие массы у детали даёт
предупреждение, техническая ошибка сохранения откатывает весь импорт.
